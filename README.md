# Mosquera Energy

## Descripción del proyecto

Mosquera Energy es una página web desarrollada como parte de una actividad integradora. Presenta mi perfil personal y profesional, mis habilidades y algunos productos relacionados con soluciones energéticas y telecomunicaciones.

# Autor

Walter Paúl Mosquera Perlaza
Tecnólogo en Telecomunicaciones.

## Tecnologías utilizadas

HTML5: estructura de la página web.

CSS3: diseño, colores y presentación.

JavaScript: funcionamiento de los botones interactivos.

Phoenix Code: editor utilizado para desarrollar el proyecto.

Git y GitHub: control de versiones y almacenamiento del código.

GitHub Pages: publicación de la página en internet.

# Funcionalidades

## Menú de navegación entre secciones.

## Presentación personal con fotografía de perfil.

Sección de habilidades.

Tarjetas de productos con imágenes y descripciones.

Botones «Ver más» con información adicional.

Formulario de contacto con mensaje de confirmación y limpieza automática de campos.

Nota: El formulario es demostrativo y no envía correos electrónicos reales.

Inversores de corriente.

Aplicar los conocimientos adquiridos sobre desarrollo web mediante la creación y publicación de un portafolio personal, utilizando HTML, CSS, JavaScript y GitHub.

Cómo visualizar el proyecto

Ingresar al repositorio de GitHub: https://github.com/wmosquera-hash/ActividadIntegradora1

Seleccionar la opción Code y luego Download ZIP para descargar los archivos.

Descomprimir la carpeta descargada.

Abrir el archivo index.html en un navegador web.

También se puede acceder directamente a la página publicada mediante GitHub Pages:
